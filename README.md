# Abdullah Almkhlafi — Portfolio (Clean)

نسخة مستقلة من مشروع الموقع الشخصي، تركّز على استقرار النشر واستمرارية حفظ المحتوى والوسائط عبر Hostinger.

## المكونات

- واجهة **React + TypeScript**.
- خادم **Node.js / Express**.
- قاعدة **MySQL** لحفظ بيانات التطبيق.
- مسارات للمحتوى والوسائط وتسجيل الدخول والنسخ الاحتياطي.
- اختبارات للمسارات الخلفية والتحقق من البيانات.

> هذه نسخة مستقلة لإصلاح مسار النشر. لا تُعدّ بديلًا تلقائيًا للمستودع الأصلي أو للموقع المنشور.

## التطوير المحلي

```bash
npm ci
npm test
npm run lint
npm run build
```

تُبنى الواجهة في `dist/` والخادم في `dist-server/index.js`.

## النشر

راجع [دليل Hostinger](docs/deployment/hostinger-clean-launch.md) و[إعداد تطبيق Node.js](docs/deployment/hostinger-node-app.md).

يتطلب تشغيل الخادم متغيرات البيئة وقاعدة MySQL مُهيأة. استخدم `.env.example` مرجعًا فقط، ولا ترفع `.env` الحقيقي أو كلمات المرور إلى GitHub.

## النطاق

التوثيق هنا يصف البنية الموجودة في المستودع، ولا يفترض نجاح النشر أو اكتمال اختبار جميع الوظائف على الإنتاج.
